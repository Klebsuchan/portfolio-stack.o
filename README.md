## 🚀 Sobre o Projeto

Este repositório contém o código-fonte da landing page oficial da **Stack.O**, desenvolvida com foco extremo em performance, acessibilidade e conversão. A interface foi construída utilizando práticas modernas de desenvolvimento front-end, garantindo uma experiência fluida a 60fps, com animações ricas e um design visualmente impactante ("dark mode premium").

## 🛠 Tecnologias Utilizadas

A arquitetura do projeto foi desenhada para ser leve e extremamente rápida:

*   **Framework:** [React 18](https://react.dev/)
*   **Build Tool:** [Vite](https://vitejs.dev/)
*   **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
*   **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
*   **Animações:** [Motion (Framer Motion)](https://motion.dev/)
*   **Ícones:** [Lucide React](https://lucide.dev/)

## ✨ Principais Funcionalidades

*   **Design Responsivo e Imersivo:** Layout fluido que se adapta perfeitamente a dispositivos móveis, tablets e desktops.
*   **Animações de Alta Performance:** Utilização de animações baseadas em GPU para garantir 60fps sem engasgos.
*   **Internacionalização (i18n):** Suporte nativo para múltiplos idiomas (Português e Inglês), com troca em tempo real.
*   **Componentes Interativos:** Demonstrações visuais de código (refatoração live) e painéis de dashboard (glassmorphism).
*   **Integração Direta via WhatsApp:** Fluxo de contato simplificado e direto para os fundadores da empresa.

## 📦 Como Executar o Projeto Localmente

Siga as instruções abaixo para rodar o projeto no seu ambiente de desenvolvimento local.

### Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) (versão 18 ou superior) e o `npm` instalados na sua máquina.

### Instalação

1.  Clone este repositório:
    ```bash
    git clone https://github.com/sua-organizacao/stacko-landing-page.git
    ```

2.  Acesse o diretório do projeto:
    ```bash
    cd stacko-landing-page
    ```

3.  Instale as dependências:
    ```bash
    npm install
    ```

4.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```

5.  Acesse o projeto no seu navegador, geralmente no endereço `http://localhost:5173` ou `http://localhost:3000`.

## 🏗 Estrutura do Projeto

A estrutura de diretórios foi pensada para ser modular e escalável:

```text
├── public/              # Assets estáticos (imagens, ícones)
├── src/
│   ├── components/      # Componentes React reutilizáveis (UI e seções)
│   ├── contexts/        # Contextos globais da aplicação (ex: LanguageContext)
│   ├── index.css        # Estilos globais e configurações do Tailwind
│   ├── main.tsx         # Ponto de entrada principal da aplicação
│   └── App.tsx          # Componente raiz
├── tailwind.config.js   # Configuração do Tailwind CSS
├── vite.config.ts       # Configuração do Vite
└── package.json         # Dependências e scripts do projeto
```
